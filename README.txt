VIBES & PROMOTE — STARTER APP

Files:
- index.html: the mobile-friendly app
- manifest.webmanifest: installable web app settings
- sw.js: basic offline caching
- README.txt: this guide

IMPORTANT SETUP
1. Upload all four files to the ROOT of your GitHub repository.
2. Enable GitHub Pages from repository Settings > Pages, using the main branch and root folder.
3. Open the published Pages address on your phone.
4. In the app's Settings section, enter your business WhatsApp number in international format, e.g. 2567XXXXXXXX, without + or spaces.

CURRENT LIMITATIONS
- This is a progressive web app starter, not a native Android APK.
- Enquiries are sent through WhatsApp; there is no server, database or admin dashboard.
- Budget estimates run in the browser and are not stored centrally.
- Digital product buttons send enquiries only. Automated mobile-money payments and automatic file delivery are not configured.
- Never ask customers to send mobile-money PINs or passwords.
